# SkinForge Pocket

Editor táctil de skins de Minecraft en formato PNG 64×64, diseñado para Safari en iPhone y otros navegadores móviles.

## Sitio

La aplicación se publica mediante GitHub Pages en:

`https://sgalvez.github.io/minecraftskin/`

## Funciones

- Pintura por píxel con lápiz, borrador, relleno y gotero.
- Selección de cabeza, torso, brazos y piernas.
- Edición de frente, espalda, lados, parte superior e inferior.
- Capa base y capa externa transparente.
- Botón **Generar random** para crear una skin completa y modificable.
- Simetría horizontal, deshacer y rehacer.
- Importación de PNG 64×64 y 128×128.
- Exportación y uso de la hoja Compartir de iOS cuando está disponible.
- Guardado automático local en el navegador.
- Interfaz responsive sin dependencias ni proceso de compilación.

## Desarrollo

El proyecto utiliza HTML, CSS y JavaScript estándar. No requiere instalación:

```bash
python3 -m http.server 8000
```

Luego abre `http://localhost:8000`.
